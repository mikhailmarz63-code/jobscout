jobscout helper

Normally you never paste this: Pair with the board asks the board for it, which the board allows only from this machine and only for the allow-listed extension id (python3 helper.py install sets that up). The token reads the whole jobscout database. It is stored only in this browser's extension storage and sent only to the board URL above.

What this helper does

On Greenhouse, Ashby, Lever, Workable, SmartRecruiters and Workday pages it reads the form's labels, asks the board for the answers jobscout already prepared, and lets you copy or fill them one at a time. It never presses Submit. Add the extension's id to jobscout/.board-extension (one line: chrome-extension://<id>) and restart the board so the API accepts it.
